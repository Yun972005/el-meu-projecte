# Funcionalitats

## Què pots fer?

- **Registrar** les teues plantes amb foto i nom
- **Rebre avisos** de reg i abonament
- *Consultar* consells segons l'espècie

## Exemple de recordatori

Així guardem internament un recordatori (només per a curiosos):

```python title="recordatori.py"
planta = {
    "nom": "Monstera",
    "reg_cada_dies": 7,
    "llum": "indirecta"
}
print(f"Regar {planta['nom']} cada {planta['reg_cada_dies']} dies")
```

## Com començar

1. Crea un compte.
2. Afig la teua primera planta.
3. Activa les notificacions.

!!! tip "Consell"
    Fes una foto de la planta per a identificar-la millor.
