# 🌱 PlantCare

![Imatge de PlantCare](https://placehold.co/900x300/2e7d32/ffffff/png?text=PlantCare){ width="100%" }

**PlantCare** és una aplicació pensada perquè *mai més se't mori una planta*.
Et recorda quan regar, quanta llum necessiten i com cuidar-les.

## Per què PlantCare?

- Fàcil d'usar, **sense coneixements tècnics**
- Recordatoris personalitzats per a cada planta
- Funciona al mòbil i a l'ordinador

## Vols saber-ne més?

Visita la pàgina [El projecte](projecte.md) o consulta les [Funcionalitats](funcionalitats.md).
